# skill-slide

Skills do Claude para gerar material de aula.

## aulas-logistica-senai

Gera os slides das aulas (PPTX) no estilo SENAI a partir do PER do curso: uma apresentação por Unidade Curricular, com aulas de 4 horas (abertura, dois blocos de conteúdo e a última hora para fixação).

- Pasta: [`.claude/skills/aulas-logistica-senai`](.claude/skills/aulas-logistica-senai)
- Como usar: carregue a skill no Claude e envie o PER (PDF, DOCX ou texto). O Claude lista as UCs encontradas, confirma o nome do professor e gera os arquivos.
