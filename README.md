# skill-slide

Skills do Claude para gerar material de aula.

## aulas-logistica-senai

Gera os slides das aulas (PPTX) no estilo SENAI a partir do plano de aula: uma apresentação por Unidade Curricular, com cada aula do plano em 4 horas (abertura, dois blocos de conteúdo e a última hora para fixação).

- Pasta: [`.claude/skills/aulas-logistica-senai`](.claude/skills/aulas-logistica-senai)
- Como usar: carregue a skill no Claude e envie o plano de aula (Word, PDF, Excel ou texto). O Claude segue as aulas do plano e gera os arquivos.
